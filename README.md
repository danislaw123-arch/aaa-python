# aaa-python

## Решение первого домашнего задания по Python

## Требования

- Python 3.12+
- Сторонние библиотеки для запуска не нужны, используется только стандартная библиотека


## Установка
Склонировать репозиторий:
```bash
git clone https://github.com/danislaw123-arch/aaa-python.git
cd aaa-python
```
Дополнительно ничего не нужно устанавливать.

## Запуск

Каждая задача запускается отдельно из корня репозитория:

```bash
python3 hw1/1номер.py
python3 hw1/2номер.py
python3 hw1/3номер.py
python3 hw1/4номер.py
python3 hw1/5номер.py
```
